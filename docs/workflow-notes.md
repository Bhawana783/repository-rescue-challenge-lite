# Workflow Notes

1. Create a feature branch for each change.
2. Make focused changes and review the diff before committing.
3. Run the application and relevant checks locally.
4. Use meaningful commit messages that describe the change.
5. Open a pull request for review when working with a remote team.
6. Merge the feature branch into `main` only after validation.
7. Never force-push over shared history.
8. Resolve merge conflicts carefully and verify the application again afterward.
